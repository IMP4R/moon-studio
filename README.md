# moon — coding studio

Статический сайт студии и каталог проектов.

**Сайт: https://imp4r.github.io/moon-studio/**

Публикация GitHub Pages из ветки `main`, корень репозитория. Python-сервер не требуется. Пути к ресурсам относительные и работают в подкаталоге Pages. Ссылки проектов ведут в 42 отдельных репозитория IMP4R; исходные локальные ZIP не копируются в сайт.

`moon-3d.js` и `category-3d.js` — готовые браузерные сборки с Three.js; оригинальный moon preset и пререндеренные fallback-изображения сохранены. Three.js распространяется под MIT License (https://github.com/mrdoob/three.js/blob/dev/LICENSE).

Контент и оформление перенесены из текущего локального портфолио без изменения оригинала.
